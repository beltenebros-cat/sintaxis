Panel privado — sube archivos directamente al repositorio

Este panel sube archivos a GitHub usando un token de acceso personal que solo se guarda en este navegador (no viaja a ningún otro sitio). Úsalo solo en tus propios dispositivos y revoca el token si alguna vez lo compartes o pierdes el ordenador. Ver instrucciones abajo.

1. Conexión con GitHub

Se guarda solo en este navegador (localStorage), nunca se envía a ningún sitio salvo a la API de GitHub. Instrucciones para crearlo más abajo.

2. Archivo a subir

Puedes seleccionar varios archivos a la vez.

Cómo crear el token de GitHub

  1. Entra en GitHub → foto de perfil → Settings.
  2. Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. En Repository access, elige "Only select repositories" y selecciona sintaxis.
  4. En Permissions → Repository permissions, pon Contents: Read and write.
  5. Genera el token, cópialo y pégalo arriba. Guárdalo en un gestor de contraseñas por si lo necesitas de nuevo — GitHub solo lo muestra una vez.

Cada archivo que subas aquí crea un commit directamente en el repositorio, en la misma carpeta que usarías si lo subieras a mano desde la web de GitHub. El índice de la portada se regenera solo en 1-2 minutos.
